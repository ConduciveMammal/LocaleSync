# LocaleSync

Keep Shopify theme locale files structurally in sync by adding missing keys and removing obsolete keys without overwriting values for keys that remain.

LocaleSync uses each default storefront and schema locale as its source of truth. It copies missing keys with the default value and removes non-plural target keys that no longer exist in the source. Locale-specific plural categories remain untouched.

> [!IMPORTANT]
> LocaleSync is not yet published to npm. Build this checkout before installing it as a local project dependency or linking it to Shopify CLI.

## Features

- Discovers `*.default.json` and `*.default.schema.json` automatically.
- Adds missing nested keys and removes obsolete non-plural keys.
- Preserves translations for matching keys and locale-specific plural categories.
- Handles storefront and theme-editor schema locales independently.
- Preserves comments, trailing commas, indentation, and line endings.
- Reports structural conflicts instead of overwriting incompatible values.
- Supports dry runs, CI checks, and machine-readable JSON output.
- Creates a reversible development baseline before changing locale files.

## Requirements

- Node.js 22.12 or later.
- npm, included with Node.js.
- An existing checkout of this repository.
- A Shopify theme containing a `locales` directory.
- Shopify CLI 4 or later when using LocaleSync as a plugin.

## Set up from source

LocaleSync is not yet published to npm. These instructions assume you already have this repository checked out. Build LocaleSync once, then choose either the project-local binary or Shopify CLI integration.

### 1. Build LocaleSync

Run these commands from the LocaleSync checkout:

```bash
cd /absolute/path/to/LocaleSync
npm ci
npm run build
```

The build creates `dist/` and regenerates `oclif.manifest.json`. Run `npm run build` again after changing files under `src/`.

### 2. Choose an integration

You only need one of the following integrations.

#### Option A: project-local binary

Use this option to run LocaleSync through scripts in the theme's `package.json`. It does not register commands with Shopify CLI.

From the theme project, install the built checkout as a local dependency:

```bash
cd /absolute/path/to/theme
npm install --save-dev /absolute/path/to/LocaleSync
```

npm links the dependency to the checkout. Keep the checkout at the same path while the theme depends on it.

Merge these entries into the existing `scripts` object in the theme's `package.json`:

```json
{
  "scripts": {
    "locales:sync": "localesync sync",
    "locales:check": "localesync check",
    "locales:reset": "localesync reset"
  }
}
```

Verify the setup without changing locale files:

```bash
npm run locales:check
```

The check reports missing and obsolete keys. Differences alone still exit with status `0`.

#### Option B: Shopify CLI plugin

Use this option to add the `shopify theme locales` commands. Installing the project-local dependency does not register these commands.

Link the built checkout, then run a non-writing check against the theme:

```bash
cd /absolute/path/to/LocaleSync
shopify plugins link . --no-install
shopify theme locales check --path /absolute/path/to/theme
```

The check confirms that Shopify CLI can load the plugin and find the theme's locale files.

## Usage

These examples use the project-local npm scripts. Add flags after `--` so npm passes them to LocaleSync. Shopify CLI equivalents appear at the end of this section.

Synchronise a theme in the current directory:

> [!IMPORTANT]
> A sync can add and remove keys. Run `npm run locales:check` or `npm run locales:sync -- --dry-run` before the first write.

```bash
npm run locales:sync
```

Preview changes without writing files:

```bash
npm run locales:sync -- --dry-run
```

Check locale files without treating differences as a command error:

```bash
npm run locales:check
```

In CI, opt into status `1` when differences are found. Structural conflicts and errors continue to use status `2`:

```bash
npm run locales:check -- --fail-on-differences
```

Restore every locale file changed by LocaleSync to its exact pre-sync contents:

```bash
npm run locales:reset
```

The first real sync stores one baseline per changed file under `node_modules/.cache/localesync/backups/`. Further syncs preserve that baseline until reset succeeds, so comments, indentation, line endings, and existing translations can all be restored. Checks and dry runs never create backups. Existing `.localesync/backups/` baselines are migrated automatically, and the cache stays outside Git through the standard `node_modules/` ignore rule.

Run against a different theme or return structured output:

```bash
npm run locales:sync -- --path ./themes/example --json
```

Export a colour-free copy of the exact report generated by either `check` or `sync`. LocaleSync creates parent directories and replaces an existing destination file:

```bash
npm run locales:check -- --export ./reports/locales-check.log
npm run locales:sync -- --dry-run --export ./reports/locales-sync.log
```

Combine `--export` with `--json` to write the structured result instead:

```bash
npm run locales:check -- --json --export ./reports/locales-check.json
```

Run `npm exec -- localesync --help` for the complete command reference or `npm exec -- localesync --version` to print the installed version.

The equivalent Shopify CLI commands are:

```bash
shopify theme locales sync
shopify theme locales check
shopify theme locales reset
```

## Troubleshooting setup

### Node.js version is unsupported

Check the active Node.js version:

```bash
node --version
```

The version must be 22.12 or later. If you use Node Version Manager (nvm), the repository's `.nvmrc` selects Node.js 22:

```bash
nvm install
nvm use
```

### `localesync` is not found

Run LocaleSync through the npm scripts from the theme root. If the executable is still unavailable, rebuild LocaleSync and reinstall the local dependency:

```bash
cd /absolute/path/to/LocaleSync
npm run build
cd /absolute/path/to/theme
npm install --save-dev /absolute/path/to/LocaleSync
npm run locales:check
```

### Shopify CLI cannot find `theme locales`

An npm project dependency does not register a Shopify CLI plugin. Rebuild and link the LocaleSync checkout:

```bash
cd /absolute/path/to/LocaleSync
npm run build
shopify plugins link . --no-install
```

### LocaleSync cannot find the theme

Pass the theme root to `--path`. That directory must contain `locales/` and one `*.default.json` storefront locale.

## Behaviour

LocaleSync treats storefront and schema locales as separate groups. For each group it:

1. Finds the single `*.default.json` or `*.default.schema.json` source.
2. Compares every corresponding target locale with that source.
3. Adds keys that are missing from the target.
4. Removes target keys that no longer exist in the source, except locale-specific plural categories.
5. Leaves the values of matching target keys untouched.
6. Reports keys whose object structure differs between source and target.

LocaleSync never translates content. A newly copied value remains in the default language until a translator replaces it.

## Development

```bash
npm ci
npm run verify
```

The verification command runs ESLint, TypeScript checks, the test suite, the build and oclif manifest generation.

Run the standalone command from source:

```bash
npm run dev -- sync --path /path/to/theme
```

Run the compiled oclif plugin directly:

```bash
npm run dev:plugin -- theme locales sync --path /path/to/theme
```

The project uses TypeScript, oclif, Vitest, and ESLint. Use `npm pack --dry-run` to inspect the files that will be published to npm.
